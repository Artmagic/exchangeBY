# Бот: курсы наличной валюты с banki.ru

## Почему Playwright
Сервер banki.ru отдаёт только скелет страницы (заглушки + подписи колонок).
Список ~249 банков подгружается JavaScript уже в браузере, порциями.
Поэтому нужен headless-браузер: он выполняет JS, ждёт данные и читает готовое.
Парсер дополнительно перехватывает сетевой JSON-ответ с курсами — это надёжнее
чтения вёрстки.

## Установка
```bash
cd banki_currency_bot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium     # обязательно! ставит браузер
```

## ВАЖНО: первый запуск с диагностикой
```bash
DEBUG=1 python parser.py
```
Парсер сохранит:
- `rendered.html` — страница после отработки JS,
- `captured_*.json` — перехваченные JSON-ответы,
- `first_card.html` — разметка карточки банка,
и напечатает список перехваченных JSON-ответов.

Если список банков вывелся — всё работает, запускайте бота.
Если пусто — пришлите вывод DEBUG и файлы `captured_*.json`: по ним
донастроим разбор под точную структуру ответа API.

## Запуск бота
```bash
export BOT_TOKEN="токен_от_BotFather"
python bot.py
```
Команды: `/rates`, `/rates EUR`, `/city sankt-peterburg`.

## Замечания
- Парсер устроен «вслепую» относительно точной структуры JSON banki.ru
  (проверить на живом сайте из песочницы было нельзя). Извлечение генеричное:
  ищет самый большой массив объектов с курсами, тянет имя/покупку/продажу.
  Один debug-прогон позволит зафиксировать точные поля.
- `scrolls` в fetch_exchange_points — сколько раз прокручивать для догрузки
  предложений. Больше прокруток = больше банков, но дольше.
- Соблюдайте robots.txt и не опрашивайте слишком часто; кэш (CACHE_TTL) помогает.
